Adapt Dex Player Guide

Everything you need to use Adapt Dex with supported Generation 1–3 Pokémon ROM hacks. Open a section below whenever you need help — no developer knowledge required.

Getting Started
  1. Choose a local Generation 1–3 ROM, or paste a supported public GitHub link.
  2. Optionally open the matching .sav or .srm file; no save is needed to browse game references.
  3. Adapt Dex displays recoverable game data and supported save information. Unverified saves stay read-only.
  4. Use the tabs across the top to browse encounters, Pokémon, trainers, moves, abilities, items, and other features.
Adapt Dex prioritizes data from the selected game over unrelated Pokémon databases.
Loading & Saving

Changes save automatically. Desktop and Android update the opened file. Browser and iOS sessions keep a recovery copy inside Adapt Dex; export a copy when you need to use it in an emulator.

  • .sav and .srm are supported save-file extensions.
  • The app checks the save structure before displaying editable data.
  • Choose a ROM each session; browser edits need to be exported as save copies.
Keep a backup of an important save before making large edits.
Pokémon & PC Boxes

With a supported save, the first tab displays the party and PC boxes. Select a Pokémon to view its information and available editing options.

  • Pokémon can be dragged between supported storage tiles.
  • Some hacks use different numbers or layouts of PC boxes.
  • Shiny Pokémon are visually marked.
  • Species, moves, forms, abilities, and types use the chosen game's data.
External Storage

External Storage is Adapt Dex storage that exists outside a single game save. It is useful for keeping Pokémon available between saves.

  • Drag a party or boxed Pokémon into External Storage to store it.
  • Drag a stored Pokémon onto a compatible empty box slot to withdraw it.
  • Use search and sorting to find stored Pokémon quickly.
  • Export an archive if you want a separate copy of your Adapt Dex storage.
Brisk Pokédex

The Pokédex combines selected-game Pokémon information with supported save progress.

  • None: no Pokédex progress is currently recorded.
  • Seen: the Pokémon has been seen.
  • Caught: the Pokémon has been obtained.
  • Shiny: a shiny copy is present or the status has been marked manually.
  • Entries include Brisk stats, abilities, evolutions/forms, movepools, locations, sprites, and cries when available.

You can manually change a displayed Pokédex status in Adapt Dex after the save has been read.

Route Encounters & Locations

Route Encounters shows locations extracted from the selected game.

  • Filter by walking, surfing, fishing rods, Rock Smash, static encounters, or gifts.
  • Search by location, Pokémon, or type.
  • Brisk's repeatable static legendary encounters only disappear permanently after a successful catch; knocking one out, fleeing, teleporting away, or losing leaves it available for another attempt.
  • Related floors and subareas may be grouped under a cleaner player-facing location name.
  • Encounter information can differ greatly from normal Pokémon Emerald.
Trainer Teams

Trainer Teams lists recoverable opponents from the selected game.

  • Search by trainer, class, Pokémon, move, ability, item, or location.
  • Each Pokémon shows the information specific to that trainer's actual team member.
  • Bosses and special trainers can differ substantially from vanilla Emerald.
Moves, Abilities & Items

These tabs display recovered reference data for the selected game.

  • Moves: descriptions, type, category, battle data, and Pokémon that can learn them.
  • Abilities: descriptions and Pokémon that can have each ability.
  • Items: descriptions, locations, and the #ID used in the imported game.
Bag

The Bag shows items from your loaded save. External Item Storage holds deposited stacks. Key items stay in the game.

  • Search stored items by name or displayed #ID.
  • Use the pocket subtabs to browse Poké Balls, medicine, berries, TMs/HMs, battle items, held items, key items, and other items.
  • Drag a stack or select Move, then choose the quantity. Key items cannot be transferred. Adapt Dex does not create items or increase quantities.
FAQ & Troubleshooting

Why does Adapt Dex disagree with a normal Pokédex website?
ROM hacks can alter Pokémon, trainers, encounters, moves, abilities and items, so Adapt Dex prioritizes the selected game.

Why is my save not loading?
Make sure you selected the actual emulator/game save file rather than a save state, ROM, ZIP, or unrelated file.

Why did an edit not appear in game?
Make sure you saved the changes from Adapt Dex and then loaded the resulting save in your emulator or game.

Why is a sprite, cry, description, or location missing?
The selected ROM may use custom or unsupported data structures. A matching source index can improve coverage.

Does External Storage belong to my Emerald save?
No. It is Adapt Dex storage kept separately from an individual game save.
